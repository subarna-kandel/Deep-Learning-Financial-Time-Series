# Deep Learning for Finance

Financial time-series workflows using MLP, LSTM, and CNN models with Gramian Angular Field representations, plus portfolio and walk-forward evaluation.

## Research modules

- Multi-asset modeling and portfolio construction.
- Walk-forward evaluation comparing leaked labels with purging and embargo mitigation.

## Execution and interpretation

Install dependencies from `requirements.txt` and run notebooks in Jupyter. Some notebooks retrieve market data online, so results can change as the data provider revises its history.

The leakage demonstration is retained as a cautionary baseline; do not present its leaked performance as a valid estimate.
